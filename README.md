## 📂 What's Inside

Each folder is a topic, and every file inside it is a standalone, compilable program.

| Folder | Topic |
|---|---|
| 🔢 `variablesOperators` | Variables, data types, operators |
| 🔀 `If_Else` | Conditional logic |
| 🔁 `LOOPS` | For, while, do-while loops |
| ⭐ `PatternPrinting` | Loop-based pattern printing |
| 🧩 `functions` | Function definitions, recurs/parameters |
| 📊 `Arrays` | 1D array operations |
| 🧮 `2D Array` | Matrices, 2D array manipulation |
| 👉 `pointers` | Pointer basics |
| 🌀 `Recursion` | Recursive problem solving |
| ⬆️ `Sorting` | Sorting algorithms from scratch |
| 🔤 `String` | String handling and manipulation |
| 🏗️ `Structures` | Structs, typedef, unions |
| 📁 `File_Handling` | File I/O, memory allocation, preprocessor |
